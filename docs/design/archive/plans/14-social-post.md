**Goal.** Design an Instagram carousel, a story, a TikTok slideshow, a Threads/Bluesky/X set or a Pinterest pin
on the existing canvas, then export numbered image files and a caption `.txt` to a folder.

## Decisions

- Templates are data with a date in `packages/shared/src/social/templates.ts`: network, ratio, pixel size, max
  frames, safe-area insets (fractions), file format; no code per network.
- The `social` output variant: `{ network, frames: Page[], caption: string }`; a frame is a `Page` with the
  template fixed by the network; the shared `<Page>` renders it; the inspector is unchanged.
- Export renders in-app first: the shared `<Page>` at the template's pixel size in an offscreen container rasterised
  through the existing preview pipeline (the way `pages.ts` does in Playwright, but inside the webview) to PNG or
  JPEG; fall back to the CLI's Playwright path (`photobook render-frames <project> --output <id> --out <dir>`,
  run like `developPublish`) if WKWebView rasterisation is not pixel-stable. Decide in step 4 by comparing both on
  one frame; record the choice in the status line.
- Files `<dest>/<slug>/01.jpg … NN.jpg` plus `caption.txt`; revealed in Finder; no network posting.

## Steps

1. **Shared.** Templates, `SocialOutputSchema` filled in (03 declared the minimal variant), `frameTemplate(network)`.
2. **Store.** `addFrame(outputId)`, `sendPageToOutput(pageId, outputId)` (copies the page, keeps asset ids, re-fits
   frames to the new ratio with the layout engine), frame cap enforced with a message.
3. **Canvas.** Safe-area guides drawn by `CanvasGuides.tsx` from the template; the page strip shows frames with the
   network's numbering; **Send page to post…** in the page toolbar and page strip context menu.
4. **Export.** Renderer choice (above); `lib/jobs/socialExport.ts` enqueues one job per frame plus the caption file;
   the Export… button opens a small sheet: destination, format, "open folder when done".
5. **Caption.** A textarea in the inspector when nothing is selected, with the network's length limit shown.

## Check

- A 10-frame carousel exports at 1080×1350 with the developed renders (compare one frame against `pages.ts` output).
- Templates Vitest: every template has a positive max frames and insets inside the page.
- Send page to post keeps element ids; undo removes the frame.
