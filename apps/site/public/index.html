Questions

Are my photos uploaded anywhere?

Only when you publish, and only to your own Cloudflare R2 bucket. There is no Gallery 30 server.

What does it cost?

Nothing. The app is MIT licensed, and hosting a few books fits the free tiers of Cloudflare R2 and Vercel.

What do I need to publish?

A Cloudflare R2 bucket and a static host such as Vercel. Designing books needs no account at all.

Which platforms does it run on?

macOS today. Linux and Windows builds are untested, and you build from source for now.

Is the site password secure?

No. It is a soft gate that keeps casual visitors out, not real access control.
